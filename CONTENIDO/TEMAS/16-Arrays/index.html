📦 ¿Qué es un Array en JavaScript?

Un array (arreglo) es una estructura de datos que permite almacenar múltiples valores dentro de una sola variable. Cada elemento del array tiene una posición llamada índice, que comienza desde 0, lo que permite acceder, modificar y recorrer sus elementos de manera eficiente. Los arrays son muy utilizados para manejar listas de datos como nombres, números, productos, entre otros, y facilitan la organización y manipulación de información en programas y aplicaciones web.
